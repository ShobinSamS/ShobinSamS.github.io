01 — FEATURED PROJECTAgentic AI / AIOps

CortexOps AI

Investigate a model’s accuracy drop. Follow the evidence.

An investigation tool that brings together model metrics, deployment history, repository changes, logs, and runbooks. LangGraph agents use local LLM inference and MCP tools to assemble a report with source citations.

FastAPILangGraphOllamaQdrantNeo4jMCP
5MCP servers
Hybridretrieval + reranking
LocalLLM inference
Explore the repository ↗
Inside the build Architecture, decisions, and verification+

The problem

An accuracy number alone doesn’t explain what changed. The investigation needs to compare operational records, retrieve supporting documents, and distinguish measured observations from model-generated hypotheses.

The implementation

FastAPI and Celery/Redis workers run LangGraph workflows with PostgreSQL checkpoints. Qdrant combines dense and sparse retrieval with cross-encoder reranking. A provenance graph supports relationship expansion, with an optional Neo4j projection.

Tool use with control

Five MCP servers provide GitHub, SQL analytics, knowledge search, monitoring, and incident tools. Investigations can pause and resume. Issue creation requires human approval of the specific action.

What was verified

The local demonstration passed 22 backend tests and four browser workflows. It uses synthetic operational data; this is an engineering showcase, not a claim of enterprise-wide production accuracy.
